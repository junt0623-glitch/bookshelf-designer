# 本棚設計 — Shelf Studio

高さ・幅・奥行きを入力するだけで、天板・地板・側面板・仕切り板（水平／垂直）・背面板の
切り出し寸法を自動計算する本棚設計ツールです。ブラウザだけで動作します（サーバー不要）。

## 主な機能

- 外形寸法（H / W / D）と板厚を **0.5mm 単位**で指定
- **部材を1つ1つ個別に設計**：部材リストは物理的な部材ごと（側面板の左右別、縦仕切り1本ずつ、棚板はセル＝列×段ごと）に1行を表示し、それぞれ板厚・奥行を個別に上書き（0.5mm単位）。図面（2D/3D）・強度計算・切り出しリストに即反映。「寸法を初期化」で寸法だけ自動に戻せる（位置は保持）
- **棚板はセル（マス）ごとに完全独立**：各列・各段の棚板を1枚ずつ移動・寸法設定でき、列ごとに段数も変えられる（選択中の列に「＋段／−段」）
- **天板・地板の接合方法**を選択：側面板の上下に「乗る」／側面板に「挟まれる」。挟まれる場合、地板を上げて下に空間（台輪・巾木用）を空けられる
- **2D図面上で部材をドラッグして位置調整**（10mmスナップ）。クリックで部材を選択し、画面上の矢印ボタンまたはキーボードの上下左右キーで**5mm単位の微調整**
- **上面・底面・側面・背面から見た図で、見える部材は実線／隠れる部材は破線＋半透明**で表示（天板・地板の接合方式に応じて自動的に切り替わる）
- **棚の空間（コンパートメント）の高さ**と**縦仕切りで区切られた各列の幅**を図面上に表示（板を動かすとリアルタイムに更新）
- **2D図面の拡大・縮小**（ツールバーの ＋／−／⟳ ボタン、マウスホイール、空白部分ドラッグでパン）
- 2D図面は正面（立面）・背面（背板）・左右側面・上下面の**6面を展開図**のように配置して表示
- 棚板の段数・縦仕切りの本数の初期値を設定。縦仕切りを動かすと各列の幅が変わり、部材リスト・強度チェックにも反映
- 3Dプレビューは 2D図面と同じ配置を元に生成（マウスドラッグで回転）
- ビス／ダボ／併用から接合方法を選択し、2D図面上に穴位置を表示
- 棚板のたわみを簡易計算し、強度の目安（実用範囲／補強推奨）を表示
- 部材リスト（W×H×T×数量）の一覧表示
- 設計図として印刷・PDF保存

## 使い方

### ブラウザで直接開く
`index.html` をダウンロードしてブラウザで開くだけで動作します。

### GitHub Pages で公開する
このリポジトリを GitHub Pages で公開すると、以下のようなURLでアクセスできます。

```
https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/
```

設定手順は [Settings → Pages] で Source を `main` ブランチ / `/ (root)` に指定するだけです。

## 技術構成

- 単一の `index.html` のみで完結（ビルド不要）
- 3D描画は [Three.js](https://threejs.org/)（CDN経由で読み込み）
- 外部サーバー・データベースなし。入力値はブラウザ内でのみ計算されます

## 注意事項

強度チェックは板を単純梁とみなした近似計算による目安です。実際の製作前には、
使用する木材の物性や金物の仕様に応じて現物での確認を行ってください。
