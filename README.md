# 本棚設計 — Shelf Studio

高さ・幅・奥行きを入力するだけで、天板・地板・側面板・仕切り板（水平／垂直）・背面板の
切り出し寸法を自動計算する本棚設計ツールです。ブラウザだけで動作します（サーバー不要）。

## 主な機能

- 外形寸法（H / W / D）と板厚を **0.5mm 単位**で指定
- **部材リストの表で各部材の板厚・奥行を個別に上書き**（0.5mm単位）。天板・地板・側面・棚板・仕切り・背面をそれぞれ違う厚み／奥行に設計でき、図面（2D/3D）・強度計算・切り出しリストに即反映。「寸法を初期化」で自動計算に戻せる
- 棚板の段数・縦仕切りの本数を設定
- **2D図面上で棚板・仕切りをドラッグして位置を調整**（10mm スナップ）。縦仕切りを動かすと各列の幅が変わり、部材リスト・強度チェックにも反映
- 2D図面は正面（立面）・左右側面・上下面を**展開図**のように配置して表示
- 3Dプレビューは 2D図面と同じ配置を元に生成（マウスドラッグで回転）
- ビス／ダボ／併用から接合方法を選択し、2D図面上に穴位置を表示
- 棚板のたわみを簡易計算し、強度の目安（実用範囲／補強推奨）を表示
- 部材リスト（W×H×T×数量）の一覧表示
- 設計図として印刷・PDF保存

## 使い方

### ブラウザで直接開く
`index.html` をダウンロードしてブラウザで開くだけで動作します。

### GitHub Pages で公開する
このリポジトリを GitHub Pages で公開すると、以下のようなURLでアクセスできます。

```
https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/
```

設定手順は [Settings → Pages] で Source を `main` ブランチ / `/ (root)` に指定するだけです。

## 技術構成

- 単一の `index.html` のみで完結（ビルド不要）
- 3D描画は [Three.js](https://threejs.org/)（CDN経由で読み込み）
- 外部サーバー・データベースなし。入力値はブラウザ内でのみ計算されます

## 注意事項

強度チェックは板を単純梁とみなした近似計算による目安です。実際の製作前には、
使用する木材の物性や金物の仕様に応じて現物での確認を行ってください。
